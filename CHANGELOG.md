# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-08-13

The first complete public release of the semantic-first BERTopic tuning skill.

### Added

- Three assurance levels—`exploratory`, `research`, and
  `publication_release`—with claim-matched authorization, review, validation,
  and delivery requirements.
- Content-based routing for short network text, long documents, and mixed
  corpora, including duplicate/source groups and parent-document safeguards.
- Corpus reconnaissance, scalable reading plans, evidence ledgers, content
  fingerprints, theme-candidate audits, and explicit publication approval.
- A cumulative one-champion tuning path across analysis units, embeddings,
  UMAP, HDBSCAN parameter families, representation, and taxonomy, followed
  only when triggered by a bounded interaction confirmation.
- Original-text semantic review for topics, risky pairs, Topic `-1`, missing
  themes, artifacts, boundaries, counter-evidence, labels, merges, splits, and
  promotion decisions.
- Portable tools for diagnostic diversity evaluation, semantic review queues,
  semantically eligible Pareto filtering, champion-trace validation, snapshot
  alignment, lexicon compilation, representation-update verification, study
  bundle validation, and visualization planning and validation.
- Auditable synonym, stopword, and custom/domain-term iteration with frozen
  assignment and topic-identity fingerprint checks for representation-only
  changes.
- Group-safe finalist stability, coverage, lineage, rollback, and
  reproducibility artifacts for research and publication use.
- Assurance-aware study templates and a layered research visualization bundle
  spanning structure, representation, taxonomy, and governance.
- An offline executable quickstart with committed inputs, expected output, and
  a byte-stable semantic-review-queue check.
- Exact user-level and repository-level Codex installation commands, an exact
  `$bertopic-tuning` invocation prompt, an MIT license, and full methodological
  references.
- A deterministic standalone plugin directory and ZIP builder sourced only
  from regular Git-index blobs, with an explicit package whitelist,
  byte-identical canonical skill projection, cross-platform path containment,
  normalized metadata, a vendored schema contract, optional official-validator
  release gates, and Linux/Windows CI coverage.
- Concise UTF-8 Codex UI metadata, matching cluster-and-champion brand assets,
  and a GitHub social preview using the approved semantic-first positioning.

### Methodological guarantees

- Original text remains authoritative for topic meaning and model promotion;
  metrics generate review queues and never issue semantic verdicts.
- Structural, representation, taxonomy, and governance changes remain
  separate and traceable.
- Candidate generation requires target-corpus evidence instead of universal
  parameter grids, thresholds, metric weights, or imported tuning recipes.
- Existing bundles without `assurance_level` remain legacy-strict and cannot
  be silently downgraded.

### Validation

- 203+ standard-library unit and integration tests cover assurance policy,
  semantic review, cumulative tuning, route evidence, selection integrity,
  reconnaissance, lexicon iteration, lineage, visualization, and study-bundle
  contracts.
- The committed quickstart reproduces its expected queue byte for byte on a
  clean output path.
